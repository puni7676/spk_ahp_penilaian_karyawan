# SPK AHP Penilaian Karyawan
Proyek ini merupakan aplikasi Sistem Pendukung Keputusan untuk menilai kinerja dan kelayakan gaji karyawan menggunakan metode Analytical Hierarchy Process (AHP).

## Fitur
- Menampilkan dataset karyawan
- Preprocessing data
- Input perbandingan kriteria AHP
- Menampilkan matriks perbandingan berpasangan
- Menghitung bobot kriteria, CI, dan CR
- Menampilkan ranking karyawan
- Menampilkan grafik hasil akhir

## Metode
Metode yang digunakan adalah Analytical Hierarchy Process (AHP).
